# Gear Ghost Agent

Agente Windows do Gear Ghost. Baixe o `GearGhost-Agent.exe` na aba Releases, rode, cole o código de pareamento mostrado em https://gear-ghost-production.up.railway.app e pronto.

O Windows pode mostrar o aviso SmartScreen (executável ainda sem assinatura): clique em "Mais informações" e depois "Executar assim mesmo".
